About the role
We are building AI agents that automate customer and internal workflows on AWS. You will design, build and deploy multi-agent systems that use retrieval, tools and memory to complete real tasks.

Responsibilities
- Design and build agentic AI applications using Python.
- Build multi-agent workflows with LangGraph and LangChain; evaluate CrewAI and AutoGen for team-based agents.
- Implement Retrieval-Augmented Generation (RAG) pipelines: chunking, embeddings, vector search and evaluation.
- Integrate agents with tools and external systems using the Model Context Protocol (MCP).
- Build and deploy agents on AWS using Amazon Bedrock and Amazon Bedrock AgentCore (Runtime, Memory, Gateway).
- Integrate the Claude API and other LLM APIs into applications; design prompts and structured outputs.
- Use AI coding assistants such as Claude Code to speed up development, debugging and testing.
- Write tests and evaluation sets to measure agent quality, and monitor agents in production.
